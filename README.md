# 🧠 Bright Minds - AI-Powered Learning Platform

[![License](https://img.shields.io/badge/license-MIT-blue.svg)](LICENSE)
[![Python](https://img.shields.io/badge/python-3.8+-blue.svg)](https://python.org)
[![Flask](https://img.shields.io/badge/flask-2.3.3-green.svg)](https://flask.palletsprojects.com/)

Bright Minds is an **AI-powered educational platform** designed for children with different learning needs including ADHD, Autism, Dyslexia, and slow learning. The platform uses semantic AI to understand natural language and provide personalized learning experiences.

## ✨ Features

- **🤖 AI Tutor with Semantic Understanding** - Uses Sentence-BERT to understand meaning, not just keywords
- **📚 Adaptive Courses** - Math, English, and General Knowledge
- **🎮 Educational Games** - Memory Match, Word Scramble, Pattern Play
- **📝 AI Assessment** - Adaptive quizzes that adjust difficulty
- **💡 Disability Awareness** - Comprehensive resources for parents and educators
- **🎯 Personalized Learning Paths** - Based on learning style assessment

## 🚀 Quick Start

### Prerequisites

- Python 3.8 or higher
